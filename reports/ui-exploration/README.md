# 사이드바·계층형 탭·매크로 UI 개편

기존 URL: https://0baselabkim-debug-qweasd-app-nuf4kg.streamlit.app/

- PC: 270px 고정 사이드바. 제목, 매크로 지표/수급 필터 메뉴, 조회 조건, 운영·출처 순서. 접기/펼치기 컨트롤 없음. 사이드바 내부 스크롤.
- 모바일(760px 이하): 메뉴 영역이 본문 위에 항상 펼쳐진 290px 영역으로 배치되며 내부 스크롤 가능. 본문과 겹치지 않도록 별도 영역을 차지함.
- 기본 화면은 매크로. 4개 지표 그룹을 PC 2열/좁은 화면 1열 카드로 표시. 표는 항목명/최신 데이터 값/전일 대비 3열만 표시. 금리 증감은 bp 및 %p. 공표 기준일 범위와 행 툴팁으로 오래된 자료 구별; 정확한 기준일/직전일/공급원/원문은 사이드바 데이터 출처에서 조회. 원본 수치와 CSV 보존.
- 투자자별 당일 순매수는 별도의 작은 표. 미검증 값은 미확보. 계산·환산·API 재수집 없음.
- 자체 무료 HTML/JS Streamlit 컴포넌트. 외부 CDN/라이브러리/유료 서비스 없음. 마우스 단일 클릭은 선택, 섹터명·종목명 셀의 dblclick 이벤트만 이동. 다른 셀 더블클릭은 이동하지 않음. 터치는 pointerType=touch/pen인 pointerup에서 1회 탭 이동. 키보드 Enter 지원.
- 기본 표 기능: 헤더 정렬, 표 내 검색, 가로·세로 스크롤. 정렬 시에도 시장+섹터 ID/종목코드를 보내므로 화면상의 행 번호와 혼동하지 않음. 서버에서 현재 허용된 ID인지 확인.
- 전체섹터 조회/실제 섹터명/실제 종목명 계층형 탭. 상위 탭 클릭 시 하위 탭 유지. hover/키보드 focus 시 X 표시(터치는 상시 표시). 종목 탭 닫기→섹터, 섹터 닫기→전체 및 하위 탭 동시 제거. 기본 탭은 닫을 수 없음.
- 기간, 시장, 분류체계, 정렬, 종목 검색 유지. 현재 필터에서 유효하지 않은 섹터/종목은 탭을 정리해 잘못된 종목을 보여주지 않음.

## 보존

preservation.json: DuckDB, 실제 매크로 스냅샷, 재무·테마 이력, 수급·확산율·거래활성도 산식, 적격성 규칙, 수집 워크플로 등 보호 파일의 변경 전후 동일 여부와 SHA-256. UI 배포 검사 워크플로만 UI 테스트를 추가했으며 수집 예약/재시도는 수정하지 않음.

## 검증 방법

pytest: 기존 데이터·산식 회귀 및 신규 탭 상태/매크로 표시 계약.
scripts/check_live_dashboard.py: 실제 Playwright 마우스 더블클릭/단일 클릭 구분, X 클릭/hover/키보드 focus, 시장별 동명 섹터, 부모·자식 탭, 조건 보존, 원본 CSV/차트/매크로 대조, 실제 모바일 터치, 화면 비겹침, 모바일→PC 리사이즈.
scripts/check_corporate_dashboard.py: 기존 공시/사업 데이터 게시와 최신 재무 패널 검증 경로를 새 탐색 UI에 맞춤.

실제 테스트 자료와 수집 데이터는 합치지 않으며, 이번 작업에서 데이터 수집은 실행하지 않음.
