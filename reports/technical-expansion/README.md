## UNVERIFIED 처리의 변경 근거

공식 KRX 문서 본문은 HTTP 403으로 열리지 않았고, 실제 일별 API에는 최종 확정 플래그나 게시 시각이 없었다.
공식 최종 시각을 확인했다고 주장하지 않는다. KRX 941/1,820행 재조회 결과는 기존 자료와 같았다.

공식 확정과 별도로 `ACCEPTED_DAILY` 운용 검증을 도입했다.
다음 한국 날짜에 확인한 공식 KRX OHLCV 6개 값이 같은 날짜 KIS J 최신 수정 일봉과 일치하고 원종가도 일치하며,
실제 KIS API 원응답의 20거래일 순매수 금액을 다시 원화로 환산한 값이 저장 수급과 일치해야 한다.
일봉/수급 해시·날짜·원응답 필드를 판정 시 다시 확인하며, 누락/불일치는 보류한다.

이번 391종목의 수급 대조는 **저장된 실제 API 원응답 재검증**이다. 새로운 KIS 조회라고 표시하지 않는다.
[원응답 대조 근거](saved-response-acceptance.json), [KRX 재조회 근거](krx-publication-review.json).
이는 이후 공급자 정정 가능성을 없애는 공식 최종 확정 보증이 아니다.
기준·한계는 [운용 문서](../../docs/technical-data-operations.md)에 기록했다.

## 기존 종가 불일치

391종목 중 보존 종가와 별도 KRX 원주가 차이는 325종목이며, 기존 6종목은 통합 시세와 값 일치 근거가 있다.
새로 확보한 종목까지 포함한 나머지 319종목의 거래소 범위 원인은 아직 확정하지 않았다.

초기 미해결 86종목은 **모두 당시 수급 응답 종가·현재가 응답 값이 보존 종가와 일치**했다.
반면 당시 저장된 수정 일봉은 **86종목 모두 현재 공식 KRX 종가와 일치**했다.
즉, 이번 저장 과정에서 만든 차이가 아니라 기존 API 응답들 사이에 이미 존재하던 차이다.
다만 이것만으로 과거 KRX/NXT 라우팅 또는 공급자 처리 원인을 확정하지 않는다.
[86종목 추적 기록](legacy-86-trace.json). 원본 DB/응답은 수정하지 않았다.
별도 기술 지표는 독립 대조한 KRX 일봉만 사용한다.
