# PC 가독성 및 콘텐츠 폭 조정

UI 스타일만 변경. 데이터·계산·탐색·소수점 정밀도·색상·수집 예약은 유지.

## 실측 (실제 데이터, 2026-10-14 수급)

| 화면 | 1920px 본문 폭 | 1440px 본문 폭 |
|---|---:|---:|
| 매크로 | 1,155px (가용 폭 70%) | 1,050px |
| 전체 섹터/섹터 내 종목 | 1,402.5px (85%) | 994.5px (85%) |
| 종목 상세 | 1,237.5px (75%) | 980px |

270px 사이드바 유지. 모든 본문 왼쪽 정렬. 1440px에서는 매크로 2열과 상세 KPI·차트 가독성을 위해 최소 폭을 사용하며, 768/390px에서는 가용 본문 폭 100%로 확장. 넓은 표는 내부 가로 스크롤.

- 표 본문/헤더: 14px. 메타데이터·출처 보조 텍스트는 구분해 유지.
- 매크로·투자자별 수급 행: 기존 약36px → 46px, 헤더44px.
- 섹터·종목 행: 기존40px → 기본44px. 긴 섹터명은 잘라내지 않고 줄바꿈하여 필요 시67px로 확장. 헤더45px.
- 표의 열은 콘텐츠 크기에 맞추고 강제 100% 확장을 제거. 숫자 우측 정렬, 텍스트/숫자 정밀도 동일.
- 상세 KPI 세로 간격 확대, 숫자·단위 줄바꿈 지원, 차트 너비 보존. 재무 표 내용 기반 너비, 44px 행 및 값 우측 정렬.
