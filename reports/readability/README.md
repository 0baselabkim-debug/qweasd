- 표 본문/헤더: 14px. 메타데이터·출처 보조 텍스트는 구분해 유지.
- 매크로·투자자별 수급 행: 기존 약36px → 46px, 헤더44px.

- 표의 열은 콘텐츠 크기에 맞추고 강제 100% 확장을 제거. 숫자 우측 정렬, 텍스트/숫자 정밀도 동일.
- 상세 KPI 세로 간격 확대, 숫자·단위 줄바꿈 지원, 차트 너비 보존. 재무 표 내용 기반 너비, 44px 행 및 값 우측 정렬.
