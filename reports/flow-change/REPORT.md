# 외국인 수급 변화 분석 개선 결과

기준일: 2026-10-14. 최근 5일은 10월 7·8·12·13·14일, 직전 5일은 9월 29·30일과 10월 1·2·6일입니다. 두 구간은 겹치지 않습니다.

## 구현 내용

섹터는 자금 유입 상위·매수세 강화·자금 이탈로 조회합니다. 종목은 전체·매수세 강화·꾸준한 순매수·자금 이탈로 조회합니다. 오늘·5일·20일 탭, 금액·강도·변화·기존 점수 정렬과 선택 종목 차트를 유지합니다. 섹터를 변경하면 해당 섹터 종목을 자동 조회합니다. 상세 재무는 접힌 상세 표와 기존 상세정보에 있습니다.

꾸준한 순매수는 20일 중 15일 이상 양수이며 최근·직전 5일 합계가 모두 양수인 관찰 분류입니다. 실제 해당 종목은 61개입니다. 평가 점수나 가중치에 반영하지 않았습니다.

## 매수세 강화 상위 5개

개선액 = 최근 5일 순매수 − 직전 5일 순매수. 순매도 축소를 포함하며 신규 자금 유입이나 미래 가격 상승을 입증하지 않습니다. 금액 단위: 억원.

## 보존·검증

수급 48,567행과 DuckDB 파일 해시가 그대로이며, 기존 기간별 합계·수급 점수·순위와 종목 평가 해시도 동일합니다. 1,161종목의 종합 점수, 재무, 평가 가중치를 유지했습니다. 원본에서 2,430종목과 50업종의 5일 구간을 독립 계산해 2,480개 비교를 통과했습니다. API 재수집·새 공급원·유료 데이터 추가는 없습니다.

로컬 자동 테스트 81개 통과(84.31초). 부호 전환, 실제 0원, 누락, 매수 지속 조건, 필터·정렬, 새 거래일 구간 이동, 기존 데이터 보존과 실패 시 게시 방지를 검사했습니다. 테스트용 자료는 테스트 임시 DB에만 사용하며 실제 DB와 혼합하지 않습니다.

[배포 검사](https://github.com/0baselabkim-debug/qweasd/actions/runs/38660254388) · [공개 웹 조작 검사](https://github.com/0baselabkim-debug/qweasd/actions/runs/38660253588). 배포 검사와 실제 웹 조작 검사가 모두 통과했습니다. 웹에서는 강화 30업종·1,299종목, 꾸준한 순매수 61종목과 이탈 필터의 실제 값·상태·정렬을 대조했습니다. 기간 탭, 섹터 변경 시 종목 자동 조회, 차트·툴팁, CSV도 통과했습니다. 실행 결과는 daily-run.json, live.json, tests.json, validation.json에 보관합니다.

## 자동 갱신 점검

일일 갱신 워크플로는 active 상태이며 한국시간 평일 20:30 수집 시도, 23:30 미완료분 재시도로 설정되어 있습니다. 거래일·중복 게시 원장, 성공분 체크포인트, 실패 종목 재시도, 검증 후 하나의 커밋으로 게시, manifest 변경에 따른 웹 캐시 갱신 구조를 유지했습니다. 예약 실행은 지연될 수 있습니다.

[실제 성공 실행 38650326964](https://github.com/0baselabkim-debug/qweasd/actions/runs/38650326964)는 workflow_dispatch / verify_saved 모드로, 보존된 10월 14일 응답을 재검증·게시한 기록입니다. 공식 휴장일 조회도 해당 기록에서 성공했습니다. 새로운 날짜를 예약 수집·검증·게시한 이 워크플로의 성공 기록은 아직 없습니다. 이번에는 신규 전체 수집을 실행하지 않았고 미래 거래일 운영 성공을 주장하지 않습니다.

## 남은 문제

과거 업종 구성은 미확보입니다. 현재 구성 기준 수급 분석이며, 섹터 수급 부분 점수 70점과 종합 100점을 구분합니다. 상대강도·거래 활성도 배점을 임의로 보완하지 않고 종합 강세 점수는 보류합니다.

기존 종가 불일치 2,042종목 및 원천 최종 확정 시점 미검증 상태가 남아 있습니다. 원본 가격과 재무 평가는 보존했고 이번 수급 분석은 계속 가능합니다. 향후 일일 수집에서 가격 정합성 검증 실패가 생기면 기존 게시 자료를 유지하도록 되어 있습니다.

20일 불완전 종목 3개, 최근·직전 5일 비교 불완전 종목 2개는 해당 평가를 보류합니다. 매수세 강화나 지속성 분류는 수익률 예측이 아닙니다.
