## 투자 적격성: 승인 대기 초안 (미적용)

현재 2,430종목 모두 판정 보류. 감사의견/중대한 위험/자본금 등 필수 자료 미확보와 최종 규칙 미승인 때문이다. 재무상태는 수급 순위나 대상에 영향을 주지 않는다.

승인 검토안:
- 부채비율 200% 초과, 영업적자, 영업현금흐름 음수, 매출 감소는 '주의' 검토. 금융업 등 특수업종에는 일률 적용하지 않고 별도 기준 필요.
- 자본총계 0 이하, 공식 감사의견 부적정/의견거절, 공식 확인된 중대한 재무 위험은 '부적격' 검토.
- 필수 정보가 모두 검증되고 승인된 위험 조건이 없을 때만 '투자 적격'. 정보 부족은 '판정 보류'.
- 적자만으로 턴어라운드 기업을 자동 부적격 처리하지 않는다.

사용자 승인 전에는 eligibility_rules.json의 approved_by_user=false, rules=[]를 유지한다. 초안은 화면 판정에 적용되지 않는다. 부채비율은 내부 원비율과 표시 백분율을 구분해 승인 후 규칙을 입력해야 한다.
