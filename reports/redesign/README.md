# 다크 대시보드 UI 변경

기존 앱: https://0baselabkim-debug-qweasd-app-nuf4kg.streamlit.app/

- 밝은 세로형 화면을 딥 네이비·코발트 패널로 변경했습니다.
- 메인 탭 2개, 각각 오늘/5일/20일 기간 탭, 섹터 순위·차트 2열, 하단 종목 정보·KPI·재무·점수 패널을 제공합니다.
- 요청한 설명 문구·섹터 상세 토글·일별 원본 합계 토글을 제거했습니다. 공시일/출처/데이터 한계는 사이드바 및 선택 종목 정보에서 확인할 수 있습니다.
- 일별/누적/함께 보기 차트 전환, 표 정렬, 검색, 업종·테마 필터, CSV 다운로드를 유지합니다.
- 상단 업데이트 상태 버튼은 기존 GitHub Actions 운영 기록을 엽니다. 데이터 수집을 새로 요청하는 버튼은 아닙니다.
- 화면의 숫자는 기존 실제 자료입니다. 첨부 시안의 예시 숫자는 사용하지 않았습니다.

## 보존 및 검증

`preservation.json`: 실제 수급 48,567행, DuckDB SHA-256 및 기존 종합 평가 1,161종목의 점수 해시 일치. 가중치·수집 코드·수집 일정·원본 데이터 변경 없음.

자동 테스트: 기존 96개 및 차트 표시 전환의 0원/결측/누적 단절 회귀 테스트 3개 통과.

`local-browser.json`: 오늘/5일/20일 전체 종목·섹터 다운로드를 기존 원본과 대조, 점수 보존, 매수세 강화/이탈/꾸준한 매수 필터, 종목 정렬, 테마 전환, 차트 툴팁/전환 검사. 1500px 데스크톱, 768px 태블릿, 390px 모바일에서 페이지 가로 넘침 없음. 모바일 패널은 세로로 전환되며 표는 내부 가로 스크롤을 유지합니다.

섹터 100점 평가 보류 및 기존 종가 불일치 상태는 그대로 유지합니다. 이번 변경은 UI에 한정되며 새로운 데이터의 정확성이나 미래 수집 성공을 주장하지 않습니다.
