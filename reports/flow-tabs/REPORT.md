# 오늘·지난 5일·지난 20일 탭

기존 Streamlit 앱의 섹터 표와 종목 표에 독립적인 기간 탭을 추가했습니다.
탭을 변경하면 해당 기간 순매수 금액 내림차순으로 정렬하며, 기간 합계와 순위를 먼저 표시합니다.
차트와 CSV는 선택한 기간을 따릅니다. 기존 재무·가치평가 점수와 업종 내 종합 평가 순위를 유지합니다.

오늘은 선택한 실제 자료 기준일의 1거래일입니다. 5일·20일에는 기준일을 포함하며 휴장일을 제외합니다.
현재 기준일은 2026-10-14입니다. 누락은 0원으로 보정하지 않고, 불완전한 기간에는 순위를 부여하지 않습니다.
섹터 수급은 현재 구성 기준이며, 보류된 섹터 종합 강세 점수를 대신 확정하지 않습니다.

검증: 자동 테스트 63개 통과. 저장된 원본 48,567행에서 1·5·20일 합계와 순위를 독립 계산해 대조했습니다.
DB 해시와 기존 종목 평가 결과 해시가 일치하며, API 재수집은 수행하지 않았습니다.
웹 조작 및 CSV 대조 결과는 같은 폴더의 `live.json`에 기록합니다.
