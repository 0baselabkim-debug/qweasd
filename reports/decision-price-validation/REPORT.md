## 원인과 근거

1. 최신일 공식 KRX 참조자료가 없었다. 기존 분석 경로가 실제로 읽은 운영 참조자료는 주로 10/14·15였고, 연구 브랜치에 있던 10/16·19·20 자료는 연결되지 않았다. 연구 원문과 해시를 검증해 별도 참조 경로로 연결했다. 초기 KOSPI 10/16·19·20은 연결 전에 재조회된 중복 3건이 있었으며 원본을 덮어쓰지 않았다. 이후 해당 아카이브는 재사용한다.
2. 공식 10/21 자료를 실제 수신한 후 최초 KIS 관측 2,430개를 대조했다. **252개 일치, 2,178개 불일치**다. 불일치 필드별 종목 수는 종가 2,030, 고가 504, 저가 390, 거래량 1,163, 거래대금 1,163, 시가 0이다. 필드별 수는 중복되므로 합산하지 않는다.
3. 세 표본의 새로운 KIS 수정·원주가 조회는 모두 공식 KRX와 일치했다. 따라서 이 표본에서는 관측 시점 사이에 값이 바뀐 현상을 확인했다. 공급자 내부 변경 사유, 정확한 확정 시각, 전체 불일치 종목의 동일 원인은 확인하지 못했다.
4. 정규 DB는 최대 약 31일, 저장된 최근 차트 묶음은 39일 수준이었다. 세 표본은 각각 수정·원주가 200일을 확보했고, 공식 지수 거래일에 맞춰 최근 **121일(4/22~10/21)**을 KRX 6필드로 대조했다. 일별 종목 API는 실제 페이지당 100행, 지수는 50행이어서 지수 세 번째 페이지가 필요했다.
5. `mod_yn=Y`는 공식 명세상 체결이 없어 시가가 없는 상태다. 기업행사 조정으로 잘못 묶지 않고 별도 보류 사유로 분리했다. `flng_cls_code=05`는 중간·분기 배당락이다. 원문 근거는 `OFFICIAL_ADJUSTMENT_FIELDS.json`에 기록했다.

## 자동 반영과 보호 범위

기존 정규 수집·가격 복구 완료 이벤트 → 제한된 KRX 참조 확보 → 저장 증거만 읽는 분석 재생성 → 해시·원본 합계 검증 → 단일 커밋 게시를 연결했다. 새로운 cron, 전체 종목 KIS 장기 재수집, 자동 매매는 없다.

자동 참조는 KRX만 실행당 최대 2회·KST 하루 최대 4회다. 당일·미래 자료 및 18:00~23:00에는 요청하지 않고 다음 날 기존 이벤트를 기다린다. **따라서 오늘 10/22 저녁 수급이 게시돼도 10/21 기술지표를 10/22 값으로 사용하면 안 된다.** 소비자는 asof와 원천 DB 해시를 확인해야 한다.

새 가격은 20일 이상 겹치는 전체 OHLCV가 같고 각 신규 날짜가 공식 대조를 통과할 때만 기존 장기 이력과 연결된다. 가격 갱신 차이가 재발하면 해당 종목은 보류하며 제한된 재검증이 필요하다. KIS 재조회는 자동 경로에 넣지 않았다. 이 조건부 자동화가 모든 종목을 매일 정상화한다고 보장하지 않는다.

보호 대상 **63개 파일 해시 동일**: 운영 DB·manifest·검증·원장·v2·v3 전체 shard·재무 DB/상태·앱·정규 수집 코드와 일정 등. `OPERATING_PRESERVATION.json` 참조. Streamlit UI는 변경하지 않았으며 이번 공개 접근 실측은 분석 JSON을 대상으로 수행했다.

## 미완료 사항

1. 2,175종목의 최신일 원천 가격 충돌은 유지한다. 세 표본의 사후 갱신 현상을 전 종목에 자동 적용하거나 대량 재조회하지 않았다.
2. LG씨엔에스 배당락을 가로지르는 장기 가격 기준은 추가 공식 기업행사 근거가 필요하다.
3. 나머지 종목의 120일 KIS 두 기준 이력 확보는 진행하지 않았다. 기존 단기 이력이 실제 검증된 종목의 지표만 제공한다.
4. 공급자의 정확한 최종 갱신 시각·내부 변경 사유는 미확정이다.
5. **새 거래일 정규 수집부터 이어지는 실제 운영 성공은 아직 관측하지 않았다.** 현재 확인한 것은 기존 10/21 자료의 실제 수집·대조·자동 게시와 재실행이다.
