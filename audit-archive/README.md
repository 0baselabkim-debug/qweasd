# 비활성 원본 감사 보관소

기존 Git 이력은 재작성하지 않았습니다. 이 폴더는 과거 원본 관측·API 응답·게시 DB·감사 보고서를 보존합니다. 앱과 수집기는 이 파일을 읽거나 갱신하지 않습니다.

`inventory.json`은 각 원본 경로, 바이트 크기, SHA256 및 이를 담은 tar.xz 파일을 기록합니다. 이전 활성 파일을 제거하기 전에 압축본을 다시 읽어 각 해시가 일치함을 검증했습니다. 과거 매매 지표가 포함된 원본 기록은 감사 목적만으로 보존하며, 실행 코드·매매 규칙·개인 저장 코드는 별도로 제거했습니다.

현재 수급 검증용 자료는 `liquidity/`, 현재 게시 데이터와 바로 이전 fallback은 `snapshot/`에 있습니다. 오래된 전체 게시 세대는 `previous-publications.tar.xz`로 보존합니다. 개인정보나 외부 Supabase 저장소는 조회·복사·삭제하지 않았습니다.
