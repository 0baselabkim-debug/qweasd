# 제한된 가격 수집과 전환 단계 비교 연구

`REPORT.md`에 결과와 한계를 정리했습니다. 이번 시세 시험 수집은 이미 종료됐으며, 추가 시세 호출은 승인되지 않았습니다. **`pilot_collect.py`를 재실행하지 마세요.**

## 입력 분리

- `inputs/pilot-response/`: 2026-10-20에 수신한 10종목 원본. 과거 신호 계산에 사용하지 않습니다.
- 이전 `research-price-recovery-20261019`: 기존 701종목의 10/19 가격과 10/15·16·19 체크포인트.
- 기존 저장소 `audit-archive`: 관측 시각이 보존된 과거 가격·수급 버전.

`compare_stages.py`는 이전 연구 파일과 원본 보관소만 읽습니다. `validate_pilot.py`는 신규 응답을 별도로 검증합니다. 모든 원본은 읽기 전용으로 취급하며 출력은 이 연구 폴더의 `results/`에만 기록합니다.

## 오프라인 재현

이전 연구와 같은 Python 환경에서 아래만 실행하면 시장 API를 호출하지 않습니다.

```bash
python compare_stages.py
python validate_pilot.py
python -m pytest -q
```

기본 입력 위치는 `/workspace/qweasd`, `/workspace/research-price-recovery-20261019`, `/workspace/offline-flow-reversal-20261019`입니다. 원본을 다른 위치로 옮긴 경우 코드의 입력 상수도 해당 **복사본 경로**로 지정해야 합니다. 전체 재현에는 이전 연구와 공개 보관소가 필요합니다. 이번 ZIP에 대용량 이전 자료는 중복 포함하지 않았습니다.

`strategy.py`는 이전 확정 조건과 동일합니다. `stages.py`는 조기·중간 **신규 확인 사건**만 추가하는 연구용 모듈입니다. 두 단계는 매수 신호나 운영 필터가 아닙니다. 날짜별 신호 수는 서로 다른 사건 집합이며 단계별 진행률로 해석할 수 없습니다.

`as-observed-panels.json.gz`에는 실제 분석일별로 사용한 가격·수급 창과 관측 시각이 들어 있습니다. `stage-coverage.csv`의 판정 불가를 신호 없음으로 변환하지 마세요. CSV 금액은 원, 상승률은 %이고, 빈 값은 0이 아닙니다.

실행 코드 및 공개 시세 응답은 연구 브랜치에만 보존했습니다. 실제 수집 실행은 39381006174, 파일 보존 실행은 39381243274입니다. 후자는 기존 첨부파일만 옮겼으며 시세 API를 호출하지 않았습니다.
