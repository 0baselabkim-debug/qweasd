# 승인 전 최소 API 계획 — 이번 실행 0회

공식 자료가 없는 날짜를 다른 날짜의 검증으로 대체하지 않는다.
`official-price-targets.csv`는 종목별 검증 대상이며, API는 종목별이 아닌 시장/날짜 일괄 응답을 우선한다.

| 단계 | API·정확한 대상 | 기본 요청 | 목적 |
|---|---|---:|---|
| 1 | KRX `stk_bydd_trd?basDd=20261016` | 1 | KOSPI 715개 이전/나중 OHLCV와 대조 |
| 1 | KRX `ksq_bydd_trd?basDd=20261016` | 1 | KOSDAQ 1,444개 대조; 별도 표본37도 두 시장 응답에서 검증 |
| 2 | KRX `stk_bydd_trd?basDd=20261020` | 1 | 연결 통과 종목 중 KOSPI 최신일 검증 |
| 2 | KRX `ksq_bydd_trd?basDd=20261020` | 1 | 연결 통과 종목 중 KOSDAQ 최신일 검증 |
| 3 | KIS `chk-holiday`, TR `CTCA0903R`, `BASS_DT=검증 대상 기준일`, 빈 `CTX_AREA_FK/NK` | 1 | 기준일 다음 실제 개장일까지 연속 달력 확인 |
| 인증 | 기존 유효 토큰 재사용, 필요 시 기존 인증 경로 | 0~1 | 신규 자격증명 없음 |

기본 **시장 데이터 5회**, 인증이 필요하면 **물리 요청 6회**다. 응답이 충분할 때의 최소치이며
페이지 누락·오류·재시도는 포함하지 않은 숫자다. 새 실행 승인을 받을 때 모든 인증/재시도를 포함한
상한을 함께 정해야 한다. 달력은 공식 예제의 ‘가급적 하루 1회’ 지침을 지키고, 불필요한 반복 호출을 하지 않는다.
기존 KIS 간격 1.05초·인증 직렬화·운영 공유 concurrency를 유지한다.

현재는 10/20 자료의 진단 계획이다. 다음 신규 신호 시험이 더 늦은 기준일에서 진행되면
단계 2는 그 최신 기준일로 교체하며 10/20을 다시 모으지 않는다. 이미 확보된 10/19 공식 자료는
재호출하지 않는다. 50개 원본 수급 복원은 성공했으므로 그 목적의 수급 API는 **0회**다.

네트워크 처리·인증·파일 검증을 포함한 소규모 예산은 **최대 5분**을 제안한다.
이는 실측 소요시간이 아니라 제안 상한이다. 성공할 것이라고 보장하지 않는다.
KRX HTTP 차단 또는 제공 오류가 나면 중단·증거 보존하고, 다른 값을 임의 선택하지 않는다.

## 단계 1 판정

- 공식 6필드가 이전 값과 같음 / 나중 값과 같음 / 어느 쪽과도 다름 / 공식 값 자체가 여러 버전임을 분리한다.
- 일치하는 공식 값이 생겨도 원본을 삭제하지 않고, 새로운 전체 가격 후보를 별도 저장한다.
- 원·수정주가가 다른 51개는 공식 원가격 일치만으로 조정 이력이 검증되는 것이 아니다.
- 23개 10/19 겹침 충돌은 새 체크포인트와 보존 공식 자료의 일치가 이미 확인되어 재조회 불필요.
  그중 22개는 10/16 충돌도 있고, 1개는 40일 내 거래 없음으로 별도 보류다.

## 추가 근거가 필요한 51개

`explicit-adjustment-differences.csv`의 51개별로 행사일·조정계수·원가격 기준·반올림/절사 및
거래량 조정 규칙을 확인해야 한다. 공식 기업행사 원문과 KIS 규칙 없이 비율을 추정해 정상 처리하지 않는다.
상지건설은 권리락 사건 원문이 있으므로 그 원문을 다시 수집할 필요는 없다.
상지건설의 기존 원종가 5,900원 확인에는 **KRX KOSDAQ `ksq_bydd_trd?basDd=20260921` 1회**가
추가로 필요하다. 이 요청까지 포함하면 기본 시장 요청은 6회(인증 필요 시 물리 7회)다.
그러나 해당 종가가 맞더라도 거래량 정밀도 규칙 확인까지 자동으로 끝나는 것은 아니다.
다른 기업까지 일괄 API를 조회하는 계획은 이번 최소 5회에 포함하지 않는다.
기존 문서 검토 후 실제 필요한 공시 접수번호/날짜/시장별로 별도 호출량을 산정해야 한다.

   이후 원주가와 수정주가가 함께 다른 값으로 바뀐 원인과 정정 이력이 있는가?

3. 각 응답 OHLCV에 정규장·시간외·대량매매·NXT가 포함되는 범위와 확정/갱신 정책은 무엇인가?
4. 기업행사 시 OHLC, 거래량, 거래대금에 적용하는 조정계수 및 소수 정밀도 규칙은 무엇인가?

KRX 대조가 값의 선택에 도움이 되어도 공급자 내부의 변경 사유까지 증명하지는 않는다.
새 신호 등록은 전체 증거와 실제 다음 개장 전 시각 조건을 통과할 때만 시험한다.
