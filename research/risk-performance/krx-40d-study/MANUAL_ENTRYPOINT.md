# KRX40 수동 진입점 연결 검증 — 2026-10-22

## 구현 범위

연구 브랜치의 기존 `.github/workflows/kis-history-probe.yml`만 KRX40 수동 실행으로 연결했다. 기본 `prepare`는 시장 API 키 없이 실행하며, `collect-batch`만 기존 `KRX_API_KEY`를 사용한다. 기존 KIS 2종목 호출은 이 연구 브랜치 진입점에서 제거했다. 운영 main의 워크플로와 18:30/21:00 예약은 수정하지 않았다.

`krx40_manual.py`는 기존 `krx40_study.py`의 prepare/collect-batch 공용 함수를 호출한다. 승인 누적 80회, 배치 20회, 호출 간격 1.05초, `kis-validation-auth` 직렬화를 유지했다. 요청 전·후 원장을 원격 보존하며, 원장이 불확실하거나 게시가 실패하면 다음 호출을 차단한다. 성공한 시장·날짜는 해시 재검증 후 재사용한다.

한국시간 23:00~다음 날 09:00 미만과 실행/대기 작업 부재를 매 호출 직전에 확인한다. **dispatch 생성 시각도 같은 승인 야간**이어야 하므로 낮에 큐에 들어간 실행이나 이전 날 재실행이 나중에 조회를 시작하지 않는다. 시간 밖에서는 기다리지 않고 실패 상태를 남긴다. 자동 배치 연결·예약·신호 등록은 없다.

최신 정상 게시본에 대응하는 일일 수집 체크포인트는 `data/daily-YYYYMMDD`에서 읽기 전용으로 가져온다. 게시 run ID, 기준일, 전체 종목 집합, KRX 범위, 요청 날짜/수정주가 옵션을 확인하고 해시와 함께 연구 경로에 보존한다. 기존 하드코딩된 10월 21일 자료가 이후 신규 게시본에 사용되지 않도록 했다. 누락·불완전 체크포인트는 차단한다.
