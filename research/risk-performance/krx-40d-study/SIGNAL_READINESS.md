# 전향 신호 준비 상태: 보류

- 이번 실행 기준일은 2026-10-21. 10/22 정상 게시를 가정하지 않았다.
- 다음 공식 개장일은 보존 CTCA0903R에서 2026-10-22로 확인. 이번 연구 검증은 10/22 09:00 KST 이후라 실제 신호를 소급 등록할 수 없다.
- 공식 40일 검증 0개, A/B/C/D 판정 불가 2,430개. 분류된 후보 0을 후보 부재로 해석하지 않는다.
- 시장 API 0/80회. 야간 조회 이후에도 원가격·조정·기업행사·가격 버전·40일 이전 필요한 스윙 문맥·수급·공식 개장일·게시/관측 시각을 함께 검증해야 한다.
- 기존 build_signal 수용 검사를 우회하지 않는다. 운영 DB와 공식 연구 문맥이 다르면 별도 연구 버전의 전체 일봉 및 원본 해시를 고정하고 검증할 연결 작업이 남는다. 기존 DB 필드를 끼워 넣거나 가격 검사 조건을 끄지 않는다.
- 이번 구현은 분류/준비 결과만 출력한다. 실제 signals 저장 호출과 신규 자동 예약은 없다. 전체 API 승인과 실제 신호 등록 승인은 별개다.
- 10/22 게시 후의 최신 기준일·다음 공식 개장일·기존 달력 응답 범위를 다시 확인한다. 특별 개장시각은 별도 공식 근거가 필요하다.
