# 상승 전환·외국인 수급 전략 위험 대비 성과

**최종 판정: 데이터 부족으로 검증 불가.** 10% 이내가 더 안전하거나 수익성이 우수하다는 결론을 내릴 수 없다. 이번에 완료한 것은 원본 시점 감사, 실제 부분 표본 재현, 결측·충돌 분리, 계산 엔진 및 수동 전향 기록 구조의 테스트다.

## 실제 산출 결과

| 항목 | 결과 |
|---|---|
| 기존 참고군 A / B / C | 36 / 15 / 20, 사후 재구성 집단 |
| 당시 증거를 재현한 A / B / C / D | 1 / 0 / 0 / 54, 10/15 부분 모집단 |
| 실제 전향 고정 신호 | 0건 |
| 5 / 20 / 60일 완결 성과 | 0 / 0 / 0건 |
| 평균·중앙값 수익률, 승률, MAE, 하위 10% | 산출 불가 |
| NAV MDD, 초과수익률, 샤프·소르티노, 신뢰구간 | 산출 불가 |
| 후속 원시/수정 관측 충돌 | 55개 진입 후보 중 54개 비교 가능, 37개 불일치·1개 비교 관측 없음 |
| 추가 시장 데이터 요청 / 실거래 / 새 예약 | 0 / 0 / 0 |

부분 표본 A군은 **하이브(352820)** 1종목이다. L2 155,300원, L3 156,500원, H3 167,000원, 신호일 종가 165,100원, L2 대비 **6.3104%**. 최근 5일 순매수 **28.54억원**, 직전 5일 대비 개선 **7.04억원**이다. 당시 검증 근거와 다음 시가 이후 검증은 별개이며 투자 추천이 아니다.

10/19 참고 중간 전환군에 10%·15%·20% 누적 상한을 적용하면 **36 / 46 / 51종목**이다. 당시 증거가 남은 10/15 표본은 **1 / 1 / 1종목**이다. 이는 후보 수 비교일 뿐 위험 대비 성과 비교가 아니다. 누적 상한 집단을 서로 더하지 않는다.

## 사전 고정 계산 규칙

- 최근 40거래일과 전후 2일 스윙, H1/L1/H2/L2/H3/L3 및 동률 규칙은 선행 전수조사 코드를 재사용한다. 해당 시점 뒤 일봉은 신호 계산에 제공하지 않는다.
- A/B는 확인된 L3가 있고 H3 돌파 전인 현재 상태다. C는 **그날 새로 종가 돌파가 확인된 사건**이어야 한다. 과거 C 상태와 10/19 수급을 묶어 과거 진입을 만들지 않는다. D는 A/B/C와 배타적이다.
- 종가 이후 정보로 다음 공식 거래일 시가 진입. 진입일을 보유 1일로 세어 5/20/60번째 거래일 종가에 청산한다. 원주가·기업행사와 거래 가능성을 확인하지 못하면 미체결/검증 대기다.
- L3 전략은 검증된 동일 원주가 기준 L3를 종가로 **엄격히 하회**하면 다음 거래일 시가 청산한다. 같은 날 고정 만기가 먼저 도달하면 고정 만기 종가 청산이다. D군은 공통 L3가 정의되지 않아 L3 전략을 적용 불가로 표시한다.
- 종목·집단·L2·L3 패턴당 최초 한 번, 같은 집단 내 동일 종목의 보유기간 중 신호는 중복 진입하지 않는다. D는 보유기간 이후 새 조건만 허용한다. A가 나중에 성공했다는 이유로 C 표본을 구성하지 않는다.
- 동등 금액 포지션의 개별 수익률을 비교하되, 자산곡선은 자본·현금·동시 보유·기업행사가 반영된 일별 NAV가 있을 때만 계산한다. 개별 거래 수익률을 순서대로 이어 붙여 MDD를 만들지 않는다. 현재 NAV 시뮬레이션은 실행하지 않았다.
- 비용은 왕복 **0 / 10 / 30 / 60bp**의 명시적 가정만 준비했다. 매수·매도에 절반씩 반영하며 `순수익률=청산가×(1-c)/(진입가×(1+c))-1`, c=왕복bp/20,000. 실제 세율·수수료라고 주장하지 않는다.
- MAE는 진입 이후 보유 중 저가를 사용하되 L3 청산일은 시가까지만 노출된다. 청산 뒤 장중 저가는 포함하지 않는다. 가격 갭·유동성·진입 실패는 별도 보존하고 불리한 표본을 조용히 삭제하지 않는다.
- 비교 가능하면 같은 시장·업종 D군 중 신호 당시 시총·20일 평균 거래대금의 로그 비율 거리 합이 작은 순서, 코드 동률 순으로 최대 3개를 매칭한다. 이번에는 조건을 갖춘 동종 대조군이 없어 실행 성과 비교를 하지 않았다.

## 핵심 질문별 답변

| 질문 | 확인 결과 |
|---|---|
| A가 B보다 손실 위험이 작은가? | 검증 불가: 완결 성과 0, 당시 B 표본 0 |
| A가 C보다 MAE가 작은가? | 검증 불가: 당시 C 신규 사건 0, 검증된 후속 OHLC 부족 |
| A가 수급 단독 D보다 시장 대비 우수한가? | 검증 불가: D54 존재하나 성과 미완결·동종 매칭 불성립 |
| 10%를 15/20%로 완화하면 위험 대비 성과가 변하는가? | 후보 수만 달라짐. 성과 우열 불명 |
| 성과가 일부 기업·업종에 집중되는가? | 성과 미확보. 당시 A1개로 대표성도 부족 |
| 다른 시장 환경에서도 일관적인가? | 검증 가능한 부분 신호일 1일. 비교 불가 |
| 현재 표본으로 전략의 유효성을 판단할 수 있는가? | 불가 |

반증 가능한 후속 가설은 “A가 B보다 비용 차감 평균수익이 높고 MAE·하위 10% 손실이 작다”로 두되, 반대 결과도 그대로 보고한다. 현재 10% 조건을 강화·완화할 성과 근거가 없다. 위험이 낮다는 사실을 전제하지 않는다.

## 편향과 통계 제한

183종목은 당시 검증 자료가 남은 부분 집단이며 전체 역사적 상장·폐지 종목을 대표하지 않는다. 일부 자료 확보·검증 성공 여부에 따른 선택편향이 있다. 이 집단의 결과를 전체 2,429개나 다른 장세로 확대할 수 없다. 성과 관측 기간이 끝나지 않은 표본은 탈락이나 수익률 0으로 처리하지 않는다.

충분한 실제 신호일이 확보되면 진입일 블록과 종목 반복을 고려한 재표본 신뢰구간, 업종 집중도, 기간별 안정성을 함께 보고한다. 현재처럼 단일 신호일·A1개·완결 성과 0인 경우 신뢰구간을 계산해 통계적 확신을 만들지 않는다. 실제 NAV와 연속 공식 거래일이 없으면 연율화 샤프·소르티노도 만들지 않는다. 업종 지수 부재를 임의 평균으로 대체하지 않는다.

## 전향 연구 구조와 미완료 범위

`forward.py freeze`는 검증 묶음·해시·가격 버전·수급·구조·실제 고정 시각을 연구 폴더에 불변 저장한다. 다음 거래일 개장 뒤 실행은 거절한다. `observe`는 후속 원문을 별도로 누적하고 `UNVERIFIED`를 유지한다. 신호와 결과 파일을 분리하고 10/19 사후 참고군은 영구적으로 별도 구분한다. 실제 새 신호 등록이나 자동 예약은 이번에 하지 않았다.

후속 5/20/60거래일이 실제로 지나고 원주가·조정·기업행사 및 거래가능성을 검증한 뒤 `engine.py`로 성과를 계산할 수 있다. 현재 `run.py`는 완결 기간이 나타나면 중단하도록 해 두었으며, 검증된 후속 자료 어댑터와 자본 제약 NAV 연결은 그때 별도 완료해야 한다. 이번 결과를 무인 백테스트 운영 완성이라고 표현하지 않는다.

보고서의 표본 수는 `summary.json`, 실제 원시 수급 220항목 독립 대조는 `verify.py`, 세부 상태는 CSV 및 테스트 로그에 재현된다. 추가 데이터 필요량은 `BACKTEST_FEASIBILITY.md`에 명시했다. 운영 코드·DB·JSON·웹·예약에는 변경이 없다.
