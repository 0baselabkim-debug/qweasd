기준일: **2026-10-19**. 추가 시장 API 호출: **0회**. 운영 DB·main·Streamlit·정기 수집·JSON 게시 변경: **없음**.

**장기 가격 원본은 삭제되지 않고 감사 보관소에 남아 있었습니다. 다만 모든 원본을 최신 자료와 그대로 합칠 수는 없었습니다.** 별도 연구용 데이터셋을 구축하고 기존 40일 A/B/C 조건을 다시 실행했습니다. 10%나 스윙 조건을 완화하지 않았습니다.

## 2. API 없이 복구한 연구용 데이터

재구성 규칙은 다음과 같습니다.

1. KRX 범위의 KIS 수정주가 원본만 사용합니다. 원종가·수정종가를 임의로 혼합하지 않습니다.
2. 이전 이력과 10월 19일 체크포인트의 겹치는 날짜가 최소 20일 이상이고, **모든 겹침 날짜의 OHLCV 6필드가 정확히 일치**할 때만 연결합니다.
3. 다른 관측 버전이 있으면 각각 후보로 검사합니다. 값이 다른 날짜를 골라 덮어쓰거나, 불일치 날짜만 빼고 연결하지 않습니다.
4. 날짜 연속성, 가격 양수·유한값, 고저가 관계, 거래량·거래대금, 상장일, 기준일 이전 관측 여부를 검사합니다.
5. 보존된 KRX 10/14·10/15 원시세와 같은 날짜의 OHLCV를 비교합니다. 현재 DB의 과거 충돌 플래그를 운영에서 해제하지 않고 연구 결과에만 대조 근거를 기록합니다.
6. 40일 구간의 알려진 기업행사 조정 표시·공식 자료 대조 불일치·무거래 구간은 별도 보류합니다. 공급자 `UNVERIFIED`는 유지합니다.

## 3. 기존 A/B/C 조건 재실행

원래 40일 창, 전후 2일 스윙, 낮아지는 고점·저점, 높은 후속 저점, 종가 돌파, 전환 확인일 저점 대비 10%, 최근 5일 양수 및 직전 5일 대비 개선 조건을 그대로 적용했습니다. 스윙은 분석 시점에 두 후속 거래일이 확보된 경우만 확정했습니다.

| 분류 | 종목 수 |
|---|---:|
| A: 수급 개선 + 전환 확인 + 저점 대비 0~10% | **0** |
| B: 수급 개선 + 전환 확인 + 10% 초과 | **2** |
| C: 수급 개선 + 전환 미확인 | **358** |
| 가격 시험 가능하지만 수급 조건 미충족 | **341** |
| 판정 불가 | **1,728** |
| 합계 | **2,429** |

A가 0개라는 결과는 이번에 시험 가능한 범위에서만 성립합니다. 판정 불가 1,728개에 A가 없다는 뜻은 아닙니다. C는 자료 부족 종목을 포함하지 않습니다.

## 4. 5일·20일 성과 비교를 아직 하지 못한 이유

- 현재 평가된 두 신호는 10월 19일 발생입니다. 다음 거래일 진입 및 이후 5·20거래일 가격이 연구 자료에 없어 **성과 관측 대기**입니다.
- 장기 가격 행은 2025년부터 있지만, 실제 보존 관측 버전의 가장 이른 시각은 이번 조사 범위에서 **2026-10-15 21:06:42 KST**입니다. 2025년 가격이 있다는 것과 2025년 당시 알 수 있었던 수정주가 버전이 있다는 것은 다릅니다.
- 따라서 현재 수정주가 이력을 9월 등의 과거 분석일에 그대로 대입해 신호를 생성하지 않았습니다. 관측이 존재하는 10월 15일 이후로 제한해도 10월 19일까지는 5일·20일 성과가 성숙하지 않습니다.
- 현재 원본 수급은 **23거래일**, 과거 업종 구성도 10월 14일 이전 자료가 부족합니다. 가격만 250일로 늘려도 250일 수급 백테스트가 완성되지는 않습니다.
- 장기 OHLC는 복구됐지만 수정 OHLC가 실제 당시 체결 가격과 동일하다고 보장할 수 없습니다. 후속 시험에는 다음 날 원시가·거래정지·기업행사·비용 기준도 확인해야 합니다.

평균·중앙값 수익률, 양수 비율, 최대 하락폭, 시장 대비 초과수익, 비용 차감 성과는 산출하지 않았습니다. 0%로 대체하지 않았으며 10% 제한의 실효성 판단도 유보합니다. 지금 새로 받은 과거 수정주가는 오늘 관측한 자료로 기록해야 하고, **10월 19일 당시의 정보로 소급 취급할 수 없습니다.**

## 5. 추가 확보 방법·호출량

### 공식 소스

KIS 공식 공개 예제에서 다음을 확인했습니다.

- `/uapi/domestic-stock/v1/quotations/inquire-daily-itemchartprice`
- 거래 ID `FHKST03010100`
- `J=KRX`, `NX=NXT`, `UN=통합`
- `D=일봉`, `FID_ORG_ADJ_PRC=0` 수정주가, `1` 원주가
- 실전·모의 모두 **호출당 최대 100행**

근거: [한국투자증권 공식 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_daily_itemchartprice/inquire_daily_itemchartprice.py). 조회한 문서 사본을 `inputs/official-kis-price-example.py`에 보존했습니다. 저장된 실제 원응답에서도 100행 페이지를 확인했습니다. 이번에는 새 시세 API를 호출하지 않았습니다.

60거래일은 60달력일보다 넓은 기간을 요청하고 실제 거래일 개수를 확인해야 합니다. 120일은 대략 2페이지, 250일은 3페이지로 날짜를 역방향 이동하며 조회합니다. 페이지 경계에 중복 날짜를 두고 값이 같아야 합칩니다. 휴장·신규상장·무거래·부분 응답이면 호출이나 보류가 늘 수 있습니다.

KRX 보존 API `stk_bydd_trd` / `ksq_bydd_trd`는 시장별 **원시 일별 시세 대조**에 사용할 수 있습니다. 날짜당 시장 2개를 조회한다면 60/120/250일에 최대 120/240/500개 기본 요청입니다. 다만 이 자료가 그 자체로 완성된 수정주가 시계열은 아니며 승인 범위·과거 응답 가능성·권리조정 자료를 별도로 확인해야 합니다. KRX 원종가를 수정주가로 바꿔 표기하는 대안은 사용하지 않습니다.

마지막 열은 실측이 아닌 계획 추정입니다. 인증·기준지수·KRX 대조·기업행사 확인·재시도·응답 지연·저장/검증 시간이 추가됩니다. 수급 과거 기간 확대 비용도 포함하지 않았습니다. 전체 확대 전에 소규모 시험의 실제 처리시간과 호출 제한 응답을 측정해야 합니다. 운영 작업과 공유하는 호출 간격·직렬화 제한을 바꾸지 않습니다.

## 6. 승인 요청 대상: 10종목 소규모 재조회

전체 시장을 바로 다시 수집하지 않고, 연결 불일치가 있는 정상 거래 기업 **KOSPI 5개·KOSDAQ 5개**를 제안합니다.

- KOSPI: SK하이닉스, 두산에너빌리티, 효성중공업, LG전자, NAVER
- KOSDAQ: 리노공업, 브이엠, 에스앤에스텍, 리가켐바이오, 삼표시멘트

범위는 우선 **60거래일 수정주가와 원주가**입니다. 기본 20회 종목 요청, 필요시 인증 1회·시장 기준지수 2회·KRX 시장 대조 2회로 약 **25회**, 재시도를 포함한 **물리 요청 상한 40회**, 실행 시간 상한 **10분**을 제안합니다. 성공 응답은 연구 폴더에만 저장하고 실패 시 이미 확보한 응답을 보존합니다. 예상 실행은 2~5분이지만 아직 실측하지 않았습니다.

KIS가 현재 Codex 네트워크에서 차단된다면 우회하지 않습니다. 허용된 실행 환경에서 별도 연구 작업을 실행할 수 있는지 확인한 뒤 진행하며, 운영 워크플로·main·정기 예약을 변경하는 방법은 사용하지 않습니다. 실행 경로가 확보되지 않으면 그 상태로 보고합니다.

**요청하신 사전 승인 조건에 따라 이 소규모 시세 조회도 아직 실행하지 않았습니다.** 승인 후에도 새로 받은 자료는 새 관측 시각을 가진 후보로 보존하고, 과거 당시 데이터라고 주장하지 않습니다. 120~250일·전체 기업 확대는 소규모 결과 보고 후 별도 범위를 확정해야 합니다.
