# 외국인 수급 변화 분석

기존 오늘·5일·20일 탭, 재무·실적·가치평가 점수, 가중치, 수집·게시 경로를 유지합니다.

## 보기와 정렬

- 자금 유입 상위: 선택 기간 순매수 합계가 양수인 섹터. 기본 정렬은 금액 내림차순.
- 매수세 강화: 최근 5일 합계에서 직전 5일 합계를 뺀 값이 양수인 대상. 기본 정렬은 개선액 내림차순. 순매도 축소도 포함하므로 상태를 함께 표시합니다.
- 자금 이탈: 선택 기간 순매수 합계가 음수인 대상. 기본 정렬은 금액 오름차순(큰 순매도 먼저). 변화 정렬을 선택하면 악화 폭이 큰 순서입니다.
- 꾸준한 순매수(종목): 20일 자료가 완전하고 순매수일이 15일 이상이며 최근·직전 5일 합계가 모두 양수인 대상. 관찰 편의를 위한 공개된 기준이며 기존 점수에는 반영하지 않습니다.

누적 금액·시총 대비 강도·차트는 선택한 기간에 따라 바뀝니다. 변화 상태는 어떤 탭에서도 동일한 최근 5일 대 직전 5일 비교입니다.
보기 또는 기간을 바꾸면 그 보기의 기본 정렬로 돌아가며, 이후 다른 정렬도 선택할 수 있습니다.
섹터를 새로 선택하면 종목 범위는 해당 섹터의 전체 종목으로 자동 전환합니다.
핵심 표의 상세 지표와 기존 재무지표는 접힌 상세 표 및 종목 상세정보에서 확인할 수 있고 CSV에는 모두 포함됩니다.

## 부호·결측 처리

| 직전 5일 → 최근 5일 | 상태 |
|---|---|
| 양수 → 더 큰 양수 / 더 작은 양수 | 순매수 증가 / 순매수 감소 |
| 음수 → 덜 음수 / 더 음수 | 순매도 축소 / 순매도 확대 |
| 음수 → 양수 / 양수 → 음수 | 순매수 전환 / 순매도 전환 |
| 0 → 양수 / 음수 | 순매수 시작 / 순매도 시작 |
| 양수 / 음수 → 0 | 순매수 종료 / 순매도 해소 |
| 같은 양수 / 음수 / 0 | 순매수 유지 / 순매도 유지 / 중립 유지 |
| 어느 한 기간이라도 불완전 | 판정 보류 |

두 5거래일 구간은 겹치지 않습니다. 실제 0원은 유효 관측이고 결측은 0으로 바꾸지 않습니다.
섹터는 구성 종목 중 하나라도 구간 자료가 누락되면 그 구간 합계를 보류합니다.
변화가 양수면 강화, 음수면 약화, 0이면 유지입니다. 시총 강도는 보존된 기준일 시총이 유효한 경우에만 계산합니다.
순매수 개선으로 신규 자금 유입이나 향후 가격 상승을 추론하지 않습니다.

## 평가·원본 보존

현재 구성 기준 수급 분석이며 과거 실제 업종 구성으로 소급하지 않습니다.
수급 부분 점수 70점(40+30)과 종합 강세 점수 100점을 분리합니다. 상대강도·거래 활성도는 보류하며 결측 배점을 재분배하지 않습니다.
기존 종목 점수와 가격 원본은 유지합니다. 종가 정합성 문제와 별개로 수급 추이를 계산합니다.

검증 자료: `reports/flow-change/validation.json`, `scripts/verify_flow_change.py`, `tests/test_flow_trends.py`.
