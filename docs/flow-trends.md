# 5·20거래일 외국인 수급 추이

기존 `flows.net_amount`의 실제 원화 금액만 읽습니다. API 재조회와 DB 변경은 하지 않습니다. `screener/flow_trends.py`의 계산은 수정주가 정합성 검사와 독립적입니다.

- **현재 구성 기준 수급 추이**: 선택 기준일에 정상 거래 대상으로 평가된 종목을 해당 업종에 고정하고, 그 종목들의 과거 일별 수급을 합산합니다. 구성 기준일을 화면에 표시합니다. 실제 과거 구성·당시 투자 가능 집합을 복원한 결과가 아닙니다. 테마는 확인한 현재 소속만 사용하며 여전히 부분 분류입니다.
- 5일·20일은 저장된 시장별 거래일 달력의 마지막 5일·20일입니다. 직전 5일은 최근 5일 바로 이전 5거래일입니다. 증감은 `최근 5일 - 직전 5일`의 원화 차이입니다. 음수 기준의 증감률은 표시하지 않습니다.
- 순매수 발생 일수는 20개 관측이 모두 있을 때 `순매수 금액 > 0`인 날의 수입니다. 실제 0원은 유효한 관측이며 순매수 일수에는 포함하지 않습니다.
- 종목의 기간 내 하루라도 빠지면 해당 기간 합계를 비웁니다. 업종은 **구성원 전부**의 관측이 있는 날짜만 일별 완전 합계를 표시합니다. 상장 전 날짜도 0원으로 채우지 않습니다. 일별 표에 수신/대상 종목 수를 표시합니다.
- 누적선은 화면에서 선택한 기간의 첫 날부터 시작하며, 결측을 만난 뒤에는 합계를 이어 붙이지 않습니다. 막대의 일별 관측은 남아 있습니다. 차트는 기간 변경·툴팁과 원본 합계 CSV를 지원합니다.
- 강도는 기간 순매수 / **선택 기준일에 보존된 시가총액**입니다. 과거 시총이나 교정된 시총으로 가장하지 않습니다. 원시 시총·종가 재조회 차이는 별도 경고로 유지합니다.
- 현재 구성의 유입 강도 40점, 지속성 30점을 기존 백분위·최소 비교 대상 3개 규칙으로 계산합니다. 지속성은 20일 순매수 일수 비율과 `(최근5일 일평균 - 최근20일 일평균)/시총`의 백분위를 반영합니다. 같은 시장에서 비교하고 미분류 업종은 점수를 보류합니다. **부분 점수 /70을 /100으로 환산하지 않습니다.** 상대강도와 종합 강세 순위는 계속 보류합니다.
- 기존 종목 재무·가치평가·종합 점수와 업종 내 순위는 변경하지 않습니다. 수급 전체 순위는 현재 평가 대상 전체 종목의 금액 순위이며, 동일 금액은 공동 순위입니다. 시장/검색 필터로 기존 전체 순위를 다시 매기지 않습니다.
- ‘종목 범위 → 전체 시장’으로 전체 수급 순위를 볼 수 있습니다. 공식 업종 합계는 종목별 한 번만 포함합니다. 중복 소속 테마의 합계는 서로 더해 전체 자금 유입액으로 표시하지 않습니다.

검증: `python scripts/verify_flow_trends.py`는 보존된 원문 응답과 모든 적재 수급, 종목/업종의 기간별 합계·순위, 날짜별 구성원 완전성을 독립 계산으로 대조합니다. 테스트 가상 자료는 배포 DB에 넣지 않습니다.

## 종가 차이 검토

보관한 KIS 공식 명세는 `J=KRX`, `NX=NXT`, `UN=통합`입니다. 기존 수급·시총 요청과 후속 수정/일반 종가 요청의 코드는 모두 `J`입니다. 따라서 저장된 요청에서 KRX/NXT 시장 코드를 혼용한 근거는 없습니다. 공급자 내부 집계/갱신 시점 원인은 저장 자료만으로 확정할 수 없습니다. NXT·통합 비교 응답은 새로 수집하지 않았습니다.

이전 검증에서 3개 대표 종목의 재조회 일반 종가·수정주가·수급 부가 종가는 서로 같았지만, 저장한 종가와 달랐습니다. 그 3개 종목의 순매수 금액·수량은 같았습니다. 이것을 전체 종목 불변이나 NXT 원인 확정으로 확대 해석하지 않습니다. 기존 원본과 불일치 표시를 유지하며 금액 추이는 별도로 제공합니다.


## 기간 탭

섹터 표와 종목 표에 각각 `오늘 · 지난 5일 · 지난 20일` 탭을 제공합니다.
오늘은 선택한 실제 자료 기준일의 1거래일이며, 5일과 20일은 기준일을 포함한 거래일 합계입니다.
각 탭을 바꾸면 선택한 보기의 기본 정렬로 초기화됩니다. 자금 유입/전체 종목은 금액 내림차순, 매수세 강화는 5일 개선액 내림차순, 자금 이탈은 금액 오름차순입니다.
두 영역의 기간은 독립적이고, 차트와 CSV도 각 영역에서 선택한 기간을 따릅니다.
종목의 선택 기간 수급 순위는 현재 조회 종목끼리 비교하며, 기존 재무·가치평가 점수와 업종 내 종합 평가 순위는 유지합니다.
섹터 종합 강세 점수가 보류된 상태에서는 기간별 수급 순위로 표시합니다.

변화 분류와 보기 기준은 [외국인 수급 변화 분석](flow-change.md)을 참고하세요.
