## 실행 경로

- `feat/market-data-collector-v1`의 `.github/experiments/market-20261028-evening.json` **단독 변경 커밋** push가 전용 `market-20261028-evening.yml`을 한 번 시작한다. 코드/문서 push만으로는 시작하지 않는다.
- 날짜별 전용 Run은 authorize → 유한 대기 4단계 → 당일 공식 마스터 → 20:30 회차 → 23:30 회차 → 자동 비교로 끝난다. 반복 cron, workflow_dispatch, 외부 타이머는 등록하지 않는다.
- 대기 단계는 KIS 인증정보 없이 08:30·12:30·16:30·20:00까지 순차 대기한다. 이미 지난 대기 목표는 즉시 통과한다. 각 단계는 최대 4.5시간/한 번 30초 이하 대기다. 20:00 이후 당일 마스터와 공식 영업일을 최대 4 HTTP로 확인한다.
- 새 마스터의 적격 모집단/해시를 확정해 두 회차가 공유한다. 전날 2,349종목을 강제 재사용하지 않는다. 마스터 실패 시 종목별 수집을 시작하지 않는다.
- 두 회차는 순차 job이고 `kis-validation-auth` 공통 lock을 준수한다. 기존 작업이 인증을 점유하면 대기한다. 오래된 실험/비활성화 워크플로를 재활성화하지 않는다.

## 수집·검증·보존

기존 `kis_manual.run` 알고리즘, 외국인/기관 수급·원주가 OHLCV/거래대금·KOSPI/KOSDAQ 지수, 수급/가격 내부 일관성, 원천 SHA256, HTTP 원장, DuckDB/JSON 대조를 재사용한다. 호출 간격 1.05초, **회차당 최대 5,600 HTTP**, 만료 170분을 유지한다. 인증·실패·재시도 모두 포함하며, 기존 제한적 복구만 허용한다. 같은 회차 성공 원문은 복구에 재사용할 수 있지만 다른 회차 응답/캐시는 신규 관측으로 사용하지 않는다.

적격 N종목당 기본 `2*N+3` HTTP다. N=2,349라면 회차당 4,701회, 두 회차+마스터는 9,406회 예상이며 전체 상한은 11,204회다. 실제 모집단과 소요시간은 아직 관측하지 않았으므로 확정 수치가 아니다.

아티팩트는 `market-20261028-plan`, `market-20261028-master`, `market-20261028-2030`, `market-20261028-2330`, `market-20261028-comparison`으로 독립 보존하며 retention은 30일이다. 이는 영구 외부 백업을 대신하지 않는다. Secrets 검사 실패 시 업로드 허용 표식을 만들지 않는다. Git에는 원문 없이 작은 실행 영수증/비교 요약만 `reports/market-evening-20261028/`에 게시한다.

자동 비교는 20:30→23:30의 전체/핵심 필드, 가격, 거래량/거래대금, 외국인/기관 수급, 지수, 변경 종목/필드 상세, 메타데이터를 출력한다. 기존 숫자 정규화와 정확한 변화량/변화율을 유지한다. 원본 output1 현재 컨텍스트와 날짜가 지정된 output2는 구분되며, 핵심 필드는 지정 거래일 검증값을 사용한다. 두 회차만으로 공식 확정 시점을 단정하지 않는다. KRX 호출은 하지 않고 `PENDING_KRX`, 공급자 최종 상태는 `UNVERIFIED`를 유지한다. NXT 범위는 관측하지 않는다.
